# Реестр правил владельца

Каждое замечание владельца — здесь: чем закреплено и каким тестом проверяется.
**Код** — правило проверяет/обеспечивает программа: не вернётся.
**Инструкция** — правило только в промпте агента: модель выполняет «чаще всего», может проскочить → кандидат в код.
Тесты гоняются при каждой правке (`npm test`). Новое замечание владельца → сначала строка здесь.
