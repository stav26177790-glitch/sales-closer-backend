## 2. Как устроено сейчас

- `server.js` — 9 маршрутов: `/api/health`, `/api/ping-db`, `/api/deals` (GET/POST),
  `/api/deals/:id/history`, `/api/deals/:id/continue`, `/api/deals/:id/experience`,
  `/api/deals/:id/dismiss-stale`, `DELETE /api/deals/:id`.
- `stateMachine.js` (~1200 строк) — этапы INIT → SOPRANO_INTERVIEW → DIAGNOSING →
  (CONFLICT_RESOLUTION) → STRATEGY_SELECTION → COMPOSING → REVIEWING →
  ESCALATION / FINAL_OUTPUT (+ LOST_DEAL, DISQUALIFICATION, MEMORY_UPDATE).
- `agentRunner.js` — вызов 8 агентов, подгрузка базы знаний и кейсов отрасли.
- `agents/*.md` — промпты; `knowledge/` — 23 файла методологии + ~280 кейсов по 11 отраслям.
- Фронтенд — один `src/App.jsx` (~600 строк).

| Агент | Модель | Роль |
| --- | --- | --- |
| planner | Sonnet 4.6 | план диагностики, нужны ли уточнения |
| diagnostic | Sonnet 4.6 | 5 критериев СОПРАНО |
| strategy | Sonnet 4.6 | выбор стратегии |
| composer | Sonnet 4.6 | касания |
| reviewer | Sonnet 4.6 | проверка касаний (переведён с Haiku по A/B: 6/6 пропусков) |
| memory | Haiku 4.5 | память сделки, итог сессии |
| advisor | Haiku 4.5 | ответы на вопросы менеджера по касаниям |
| intent_classifier | Haiku 4.5 | теневой режим, только логирует |

Тесты (все зелёные на 2026-11-11):
`node static-checks.js` (13/13), `node test_escalation_manual_retry.js`, `node test_intake_round_limit.js`.
