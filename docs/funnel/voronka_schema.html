Логика воронки продаж

Четыре цепочки: основная воронка целевого лида, два сценария нецелевого лида и отдельная воронка для малого бизнеса / простого B2B. Под каждым этапом — суть того, что там происходит, чтобы разработчик понимал не только последовательность статусов, но и зачем нужен каждый переход.

Воронка 1

Целевой лид

12 этапов · от заявки до передачи в производство
01Заявка поступила
—
→
02Контакт установлен
СОПРАНО — методика вопросов
  • С — Ситуация: клиент сам описывает свою задачу
  • О — Опыт: был ли опыт в похожих вопросах
  • П — Проблемы: сложности и риски клиента
  • Р — Решение: кто принимает и как
  • А — Аналоги: готов ли рассматривать альтернативы
  • Н — Нюансы: нежелательные моменты
  • О — Ограничения: бюджет, скорость согласования
→
03Квалификация пройдена
Целевой лид, если:
  • есть привязка к объекту
  • понятен объём работ и бюджет
  • понятен ЛПР и путь согласования
  • есть срок реализации
карточка квалификации заполнена
→
04КЭВ назначен
Касания до КЭВ
  • соц. доказательства (кейсы)
  • презентация под клиента
  • формирование ТЗ
  • отправка специалиста на замеры
  • согласование дизайн-макета
  • согласование события (зум / встреча)
материалы для КЭВ подготовлены
→
05КЭВ проведён
Задача: экспертная встреча для доверия
  • техн. моменты макета, образцы, подсветка
  • разбор фотопривязки / процесс реализации
  • Москва: 902ПП + допродажи; регион — по ситуации
  • предварительный расчёт для КП
  • «что вам больше откликнулось?»
  • назначить следующее касание — презентация КП
→
06Решение и расчёт подготовлены
На основе результатов КЭВ формируется расчёт и решение для клиента.
→
07КП презентовано
Формула ФХВЭ
  • Факт — опора на ситуацию клиента
  • Характеристика — свойства продукта
  • Выгода — что это даёт клиенту
  • Эмоция — образ в голове клиента
закрытие — формула ДЧЕТ: Давайте / Чтобы / Если / То кросс-продажа предложена
→
08Возражения отработаны
Минимум 2 отработанных возражения по сделке, прежде чем двигаться дальше. Формула 100% закрытия (да/нет + описание)
  • ФВ — финансовая возможность
  • ОП — осознанная потребность
  • ЛПР — определён ли
  • Д — доверие
  • ЗС — здесь и сейчас
Касания до оплаты (экспертное / эмпатичное чередуем)
  • follow up после КЭВ: боли, риски, договорённости
  • материалы для согласования с ЛПР
  • совместное событие с ЛПР (не меньше 2 раз)
  • кейс похожего проекта
  • down/up-sell: качество, детализация, гарантии
  • сроки и слоты (пока удерживаем цену)
эмпатичные касания — короткие видео (кружки)

03Причина определена
Возможные причины
  • бюджет < 50 тыс. ₽ и не растёт

Воронка 4

Малый бизнес / простой B2B

11 этапов · от заявки до передачи в производство
01Заявка поступила
—
→
02Контакт установлен
Выясняется:
  • что нужно клиенту
  • какой объект
  • какая задача
  • ориентировочный бюджет
  • срок реализации
  • кто принимает решение
→
03Квалификация пройдена
Клиент подходит для этой воронки, если:
  • есть конкретный объект
  • задача относится к нашим услугам
  • бюджет ориентировочно 50–200 тыс. ₽
  • есть понятный срок реализации
  • проект простой и не требует глубокой экспертной проработки
  • процесс принятия решения относительно простой
важно: бюджет сам по себе не определяет воронку — сложный, перспективный проект или необходимость экспертной защиты решения переводит клиента в Воронку 1
→
04Замер назначен
Следующий шаг:
  • согласована дата и время замера
  • определён объект
  • клиент понимает, что по итогам замера будет подготовлено решение
→
05Замер проведён
КЭВ: замер проведён задача КЭВ — получить конкретные данные по объекту, после чего можно подготовить персональную визуализацию и расчёт
  • получены размеры и особенности объекта
  • зафиксированы требования клиента
  • определены технические параметры
  • собраны данные для визуализации
  • собраны данные для расчёта
КЭВ
→
06Визуализация подготовлена
На основании замера подготовлена визуализация решения для конкретного объекта клиента.
  • решение привязано к объекту
  • подготовлен визуальный вариант
  • расчёт подготовлен на основе фактических данных замера
→
07КП презентовано
Презентация решения клиенту
  • показана визуализация
  • объяснено решение
  • озвучена стоимость
  • обсуждены основные условия
  • клиенту предложен следующий шаг
→
08Условия сделки согласованы
Согласованы ключевые условия реализации проекта:
  • стоимость
  • комплектация / состав работ
  • сроки
  • условия реализации
